# FTI Fasteners Website

Simple static starter website for FTI Fasteners.

## Run locally

### Option 1 (recommended for Preview environments)

```bash
npm start
```

The server listens on `PORT` (defaults to `3000`) and serves `index.html` at `/`.

### Option 2 (quick static server)

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser.
